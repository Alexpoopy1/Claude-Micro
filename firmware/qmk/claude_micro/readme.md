# Claude Micro (QMK)

Drop this folder into `qmk_firmware/keyboards/` and build:

    qmk compile -kb claude_micro -km default

Flash by holding BOOTSEL on the RP2040 module while plugging in USB, then
copying the resulting `.uf2` onto the `RPI-RP2` drive that appears.

| File | What it does |
| --- | --- |
| `keyboard.json` | Matrix pins, encoder, RGB layout, USB descriptors — generated from `config/device.json` |
| `config.h` | Joystick, touch-strip and RGB tuning |
| `matrix.c` | 4x4 COL2ROW scan plus the thumbstick click on its own pin |
| `claude_micro.c` | Agent status LEDs, RC touch strip, joystick-to-skill mapping |
| `keymaps/default/keymap.c` | Six layers, encoder map, host-bridge keycodes |

Everything here is regenerated by `make firmware`, and `make test` fails if the
firmware and `config/device.json` ever disagree about pins, LED count or layers.
